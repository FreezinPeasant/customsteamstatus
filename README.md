# customsteamstatus
customsteamstatus is directly meant to be able to allow people to create their own Steam status without having to repeatedly change their username/description.
More information can be found within the zip file.
Also, every time you rename the status file, you will have to hide/delete the original one from your Steam library and open that same file after you rename it.
So it would be better if you downloaded multiple that could represent multiple statuses.
